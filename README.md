# 🔤 Jogo da Forca em Python

Projeto desenvolvido em Python para prática de lógica de programação, manipulando estruturas condicionais, laços de repetição e manipulação de listas/strings.

## 🚀 Tecnologias e Conceitos Utilizados
- **Python 3**
- Módulo `random` para sorteio de palavras
- Estruturas de repetição (`while` e `for`)
- Tratamento de entradas do usuário e validações
- Manipulação de listas e strings
